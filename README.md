# MAIURTH: your files

Hi Dad. Everything we've made for MAIURTH so far is in **MAIURTH.zip**.

## What's in the zip

| File | What it is |
|---|---|
| `MAIURTH-Introduction.html` | The MAIURTH intro page: the opening scene, the six-part story, and the personnel files. |
| `MAIURTH-Scene-The-Pit-Gallery.txt` | "The Pit Gallery" scene, written up as a script for a table read. |
| `Bills-Animation-Corner.html` | Your one-page Animation Corner site. |

## How to open them

1. Right-click **MAIURTH.zip** and choose **Extract All**.
2. Double-click any `.html` file. It opens in your web browser. No internet needed.
3. Double-click the `.txt` file to read the script in Notepad.

Want to change the words on the Animation Corner page? Open it in Notepad, edit the block at the top marked **YOUR SETTINGS**, save, then refresh the browser.
